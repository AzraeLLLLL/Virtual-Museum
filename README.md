# Hiyas ng Luzon: A Virtual Painting Gallery

**Hiyas ng Luzon** is an interactive virtual museum website that showcases five significant Philippine paintings connected to Luzon. The project presents Philippine art through a curated digital gallery experience with artwork analysis, historical context, and museum-inspired interactions.

## Project Overview

This website was created as a digital museum exhibit for an Art Appreciation performance task. It aims to celebrate Philippine art and cultural heritage by presenting selected paintings in a professional, interactive, and visually engaging online gallery.

The exhibit focuses on how Philippine painting reflects identity, history, memory, dignity, and cultural experience.

## Objectives

- Research and explore Philippine art and cultural heritage through documented artworks.
- Develop curatorial skills by selecting and organizing artworks into a coherent theme.
- Apply art appreciation and criticism by analyzing each artwork’s subject, content, and context.
- Create an interactive and engaging website with clear navigation and readable design.
- Present artworks using original online sources instead of AI-generated substitutes.

## Featured Paintings

The exhibit includes five selected Luzon-related Philippine paintings:

1. **Spoliarium**  
   Artist: Juan Luna y Novicio  
   Year: 1884  
   Medium: Oil on canvas

2. **Las Vírgenes Cristianas Expuestas al Populacho**  
   Artist: Félix Resurrección Hidalgo  
   Year: 1884  
   Medium: Oil on canvas

3. **La Bulaqueña**  
   Artist: Juan Luna y Novicio  
   Year: 1895  
   Medium: Oil on canvas

4. **In the Rice Field**  
   Artist: Fabián de la Rosa  
   Medium: Oil painting

5. **El Ciego**  
   Artist: Fernando Amorsolo  
   Year: 1928  
   Medium: Oil on canvas

## Website Features

- Responsive virtual museum layout
- Hero section with parallax artwork movement
- Interactive gallery with framed paintings
- Hover zoom effect for a more immersive gallery experience
- Clickable artwork inspection modal
- Subject, content, and context analysis for every painting
- Raise Lights / Dim Gallery mode
- Mobile-friendly design
- External CSS and JavaScript for modular file organization

## Curatorial Theme

The exhibit is centered on the theme:

> **Philippine painting as memory, identity, and cultural reflection.**

Each painting was selected because it represents a different way Filipino artists express history, social experience, dignity, and national identity. Together, the works form a curated route through colonial history, portraiture, agricultural life, social observation, and moral reflection.

## Artwork Analysis Framework

Each artwork is analyzed using three categories:

- **Subject** – What is depicted in the artwork?
- **Content** – What message, emotion, or idea is conveyed?
- **Context** – What historical, cultural, or social background shaped the work?
